# Bounded frequency extension: protocol before new calculations

6 October 2026. Project 1 remains mathematics -> controlled toy validation -> eventual real-model transfer. No new model family, load sweep, recursive loop or symbolic-regression fit is included.

## Question and existing evidence

For two independent Bernoulli concepts with common activation probability p, one tied-ReLU code dimension, encoder energy one, free decoder biases and importance [1,1/2], when does the clean-selected geometry share capacity and when does it retain only the important concept? For the selected geometry, how does the existing actual-decoder Gaussian-noise risk compare with the clean-selected mono control?

The p=1/5 sharing optimum and p=1/2 mono optimum are already certified. The missing step is a frequency-dependent family and valid geometry/branch comparisons. Numerical samples alone cannot establish an interval theorem or a unique transition.

## Stage A: bounded mathematical work

- Work on 0<p<=1/2 at fixed importance and load. Reuse exact bias profiling, active-branch formulas and rational geometry parameterization.
- Derive the mono local-stability condition, supplied competing branch objectives, stationarity equations and feasibility conditions.
- Attempt a global comparison covering both signs, swapped column norms, biases, boundaries and dropped-feature endpoints. State any remaining gaps explicitly.
- Stop at a proved family/transition, or at the first unresolved global comparison after the finite branch analysis. Do not broaden parameter axes to compensate.
- Any numerical checks used to select a candidate for proof are diagnostics, separately labeled and preserved. No new training is run during Stage A.

## Stage B: smallest verification, selected after the prediction

If Stage A provides a concrete transition prediction, record a separate pre-run supplement specifying a small finite set of rational p values around it and the existing certified anchor. Use the existing exact global-candidate comparison for geometry, and exact four-state Gaussian integration for risk. Define settings and stop criteria before execution. Do not launch a dense frequency/angle search or optimizer campaign.

The actual decoder rule remains strict reconstruction>.5. Report continuous reconstruction error, weighted detection error and per-feature false positives/false negatives separately. Retain both mono controls; choose the main mono comparator by the clean objective. Keep the previously evaluated noise values unless a stated mathematical crossing requires a narrowly bounded root check.

## Reporting and review

Save derivation, source, settings, raw results, failures and independent reviews. Do not alter prior experiment archives. Teacher review should check algebra/coverage and give credit for correct work, without manufacturing criticism. Root integrates findings in plan.md and posts bullets in chat after each calculation/run. Existing agent roles may be reused; no additional hierarchy is required.

A solved two-feature frequency transition is not the full variable-load theorem, a verified novelty claim or a real-model result.
