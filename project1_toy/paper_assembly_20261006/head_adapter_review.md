# Independent review of fixed class-head adapter

6 October 2026. Prospective source review before reconstruction fitting or noisy evaluation; extraction was already running under the professor-approved protocol. No experiment, outcome inspection, new mathematics, model change, or feature reselection was performed in this review.

## Decision: GO, conditional on successful extraction and the declared gates

The extraction and evaluation adapters implement the approved fixed-pair operational test. **No necessary source correction was identified.** Authorization is for this single pair and fixed numerical protocol, not another pair if a gate fails. A numerical observation from this test will not certify hidden-feature monosemanticity or full-model robustness.

## Checks against the prospective protocol

- **Fixed mapping and actual head:** extraction verifies the official category strings at output IDs 281/207 are tabby/golden retriever before inference. It checks the full checkpoint SHA-256 against the earlier cached official checkpoint. `resnet18(weights=weights).eval()` followed by `model(batch)` runs the actual complete frozen backbone, pooling and classification head; it does not turn central-cell hidden activations into counterfeit head outputs. All parameters have gradients disabled and inference uses `torch.inference_mode()`.
- **Targets and source preservation:** the adapter preserves all 1,000 signed logits and all CIFAR labels, then forms exactly `maximum(raw[:, [281,207]], 0)`. There is no logit shifting, threshold search, probability substitution, breed aggregation, or alternative feature search. Categories, checkpoint/data hashes, preprocessing representation, runtime versions, source/protocol snapshots and output hashes are saved.
- **Image selection:** extraction performs one `default_rng(20261007).permutation(len(dataset))`, takes 4,608 observations, and makes the required consecutive splits 256/256/4,096. Selection uses image indices, not class labels or scores. Official transforms, batch size 32 and four CPU threads match the protocol. The 1,200-second clock is checked before every batch; the remaining current batch can finish after that check, so this is a batch-boundary budget rather than a hard process timeout. Partial logits, labels and failure provenance are preserved if an exception occurs.
- **Class-association stopping gate:** evaluation uses only training labels for tabby-versus-cat (CIFAR label 3) and golden-retriever-versus-dog (label 5). Its rank-sum AUROC correctly uses average ranks for ties and rejects missing positive/negative classes. Both AUROCs must be strictly above .65. A failed gate saves a stopping decision before normalization, clean selection, or noisy evaluation; no replacement pair exists in the adapter. Test association is descriptive and recorded only after the clean gate passes.
- **Normalization and clean selection:** RMS is fitted on training targets only, without centering, and then applied to all splits. Positive RMS and variance are required; nonnegative targets imply positive means once RMS is positive. At least one exact-zero fraction is checked before noisy evaluation. Existing `clean_selection` is reused unchanged: both mono orientations and omitted-feature constant loss, grids 256/512, one best-cell refinement each, fixed agreement/gain/mixed-energy/success gates. There is no raw-channel selecting CLI call. The resulting angular search is a numerical selection, not a global empirical-geometry theorem.
- **Matched controls:** both model families have scalar code and encoder norm one; both use the same tied ReLU form, importance (1,2/3), data splits and Gaussian code corruption. The mono risk includes the omitted coordinate. Both zero-noise biases are fitted on the calibration split; frozen policy keeps those biases and calibrated policy refits both models' biases on that same split at each fixed noise level. Test arrays are used only for losses and descriptive association.
- **Risk and calibration:** the imported reviewed routines use decoder noise standard deviation `sigma * abs(w_i)`, the correct marginal for shared scalar Gaussian code noise under tied decoding. Additive per-coordinate weighted MSE depends on these marginals; a joint Monte Carlo simulation is unnecessary for that declared target. The training variance reference, five fixed multipliers, gap 1e-7 per model, slack 1e-12, maximum 20,000 expansions/output and shared 300-second deadline are unchanged. Every ledger and resolved flag is retained. An unresolved case can still have a saved incumbent risk/interval; it must be reported as unresolved and cannot support a certified calibrated ordering.
- **Bootstrap pairing and primary outcome:** each bootstrap uses the same held-out image indices for every model, policy and noise. Integer indices are drawn with NumPy's default integer dtype and only then cast to `uint16`; all values are at most 4,095, so the cast is lossless and does not alter the random draw. The saved 2,000-by-4,096 index array supports independent recomputation. The calibrated delta at .4 remains the prospective primary outcome. Percentile intervals are pointwise and conditional on the selected/fitted models, not simultaneous or training-uncertainty intervals. Positive sharing-minus-mono delta favors mono.

## Interpretation, scope and stopping

The professor's claim ceiling is appropriate. These are externally class-mapped **output evidence coordinates**, with a fixed checkpoint-dependent rectification gauge. CIFAR cat/dog labels do not establish the specific tabby or golden-retriever subclasses, and zero is not concept absence. No attack on image inputs or intervention inside the original ResNet is made. A favorable result can establish a compression/noisy-reconstruction tradeoff for this one operational pair, not a general semantic or safety claim.

A reversal requires resolved held-out clean and noisy orderings with opposite signs. Positive policy contrast alone is insufficient. Preserve failed gates, unresolved calibration and unfavorable values. Complete the fixed run once, independently audit saved outputs, and stop for the paper-strength decision; do not extend noise, threshold, pairs, model, optimizer or training after viewing outcomes.

The subsequent saved-record audit should verify raw-logit-to-target equality, indices and labels, exact category/checkpoint provenance, RMS and training gate recomputation, selected geometry and calibration gap ledgers, all conditional Gaussian losses, and paired bootstrap summaries. This review approves source correspondence; it does not certify future results before that audit.
