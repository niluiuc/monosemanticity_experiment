# Controlled visual bottleneck boundary, registered before training

## Question and connection
Does the exact five-concept pentagon-versus-mono concept-detection boundary survive a CNN learning the two-dimensional code directly from images? The target, matched midpoint detectors, total target encoder energy2, all-five error accounting and Gaussian code-noise corruption remain those of the verified pentagon formula. Unlike the earlier visual-front-end pilot, there is no explicit recovered five-vector followed by a separate compressor at inference: the CNN outputs the two-dimensional bottleneck directly. The desired concept geometry is imposed by supervised code targets, not discovered in arbitrary real networks. This is a controlled semi-synthetic image experiment, not ordinary CIFAR classification or pixel-noise robustness.
