# Publication snapshot integrity

The included-file manifest records relative paths, byte sizes and SHA-256 hashes for every workspace file copied into this branch. The repository README and these audit metadata files are additions for navigation/provenance.

Personal receipts/discussion archives, all LaTeX source/build files and every PDF except the requested derivation volume were excluded. Three code/results ZIPs were copied unchanged after checking their entries for excluded file types.

GitHub push protection identified embedded Mapbox secret tokens in two external webpage wrappers. Those HTML files were omitted; their extracted article text and source provenance remain available. No protection bypass was used, and the original local archive was not changed.

Historical provenance records may mention files retained locally but deliberately excluded from this public snapshot. This is not corruption of the original archives. Do not overwrite raw experiment directories during reproduction.
